# Migration Labs

This folder contains database migration and modernization labs.

## Current Lab

- [Oracle Database 19c to Oracle AI Database 26ai with GoldenGate](oracle-19c-to-26ai-goldengate/README.md)

## Standard for New Migration Labs

Each migration lab should include:

- business/technical objective
- source and target platforms
- architecture diagram
- compatibility constraints
- prerequisites
- migration method
- validation plan
- rollback plan
- troubleshooting notes
- final outcome
